Avec les « équipes d'agents », plusieurs agents travaillent en même temps sur un même projet, chacun sur sa partie. Le rôle du développeur se déplace : moins écrire, davantage répartir le travail et relire. Ça va dans le sens de ma façon de faire : plus l'outil produit vite, plus je dois comprendre ce qu'il me rend avant de le garder. C'est encore un aperçu de recherche, donc je le suis sans m'y fier les yeux fermés.

[english]

With “agent teams”, several agents work on the same project at once, each on its own part. The developer’s role shifts: less writing, more splitting up the work and reviewing it. It matches the way I work: the faster the tool produces, the more I need to understand what it hands back before I keep it. It is still a research preview, so I follow it without trusting it blindly.
