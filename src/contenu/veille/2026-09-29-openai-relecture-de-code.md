La relecture de code et la recherche de failles arrivent dans les mêmes outils que ceux qui écrivent le code. Je le prends comme un rappel : générer n'est qu'une étape, vérifier en est une autre. Une relecture automatique peut faire un premier passage ; la décision de mettre en ligne reste la mienne.

[english]

Code review and vulnerability scanning are moving into the same tools that write the code. I take it as a reminder: generating is one step, checking is another. An automatic review can take a first pass; the decision to ship stays mine.
