Cet avis réunit quatre risques à la fois : exécution de code à distance, élévation de privilèges, contournement de la politique de sécurité et atteinte à la confidentialité des données. Windows 10 et Windows 11 sont concernés tous les deux. Pour quelqu'un qui écrit des outils de vérification Windows, c'est la base : savoir si un poste est à jour est le premier constat à faire, avant toute analyse plus fine.

[english]

This advisory covers four risks at once: remote code execution, privilege escalation, security policy bypass and loss of data confidentiality. Windows 10 and Windows 11 are both affected. For someone who writes Windows verification tools, this is the baseline: knowing whether a machine is up to date is the first thing to establish, before any finer analysis.
